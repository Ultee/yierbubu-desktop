# 秒薪桌宠

当前版本：1.3.3，桌宠为用户确认的“一二”白色角色，使用内置 SVG 绘制，支持自备密钥的 AI 陪伴。

一个本地运行的 Windows 桌宠：填写税后月薪和作息后，右键一二选择“查看”可看到当天已赚金额、秒薪和下班倒计时。

## 运行

需要 Node.js 22 或更高版本。

```powershell
npm install
npm start
```

首次启动会打开设置窗口。填写扣除个税和个人承担的五险一金后的实际到账固定月薪，选择工作日、上下班时间和午休。工资设置保存在本机；AI 默认关闭，未授权收入时不会自动向 AI 发送工资与收入数值。

右键一二选择“查看”展开收入卡片，再次选择或点击卡片“×”收起；悬停和左键点击不会展开。打开后移开鼠标仍可继续查看，重启默认收起。左键拖动一二也会收起，右键打开查看、设置、大小和退出菜单；系统托盘提供相同入口。

上班时在桌前敲键盘，午休时躺着闭眼并飘出 Zzz，下班后挥手。点击随机触发比心、招手、鼓掌、点头、害羞、伸懒腰中的一种；有多个动作可用时不会连续重复。设置的“一二的互动”区域可单独开启或关闭每个动作，也可全部关闭。拖动不触发点击动作。

右键、系统托盘菜单或设置中可选择小号 75%、中号 100%、大号 130%。只缩放宠物，收入卡片字号保持不变。大小与动作开关在重启后保留；旧版工资和作息会自动兼容。

## AI 陪伴

设置页顶部点击“AI 陪伴”，选择服务商或自定义 OpenAI 兼容 Chat Completions 接口，填写模型、Base URL 和自己的 API Key，点击“测试连接”，成功后启用并“保存 AI 设置”。测试使用草稿，不改动保存配置。密钥留空保留旧值，更换接口时须重新输入对应密钥，移除按钮需保存生效。本地模型可使用回环 HTTP 地址；如服务不校验密钥，可填写本地占位值。预设模型与接口仍需对应服务商账号具备访问权限。

支持称呼；预设性格（温柔陪伴、活泼可爱、毒舌、打工人嘴替）或自定义人设 Prompt；主动说话（关闭、作息节点、自定义分钟间隔）；聊天记忆；收入授权。选择自定义间隔后可填1～1440的整数，例如10或20分钟，旧版默认30分钟。保存后重新计时，重启记住间隔；只在工作和午休期间触发，按10秒轮询检查。AI 设置与工资设置分别保存，无需先填写工资即可配置 AI。通过收入卡片“聊”、右键或托盘打开独立聊天窗口。

密钥仅主进程持有，使用 Windows 系统加密保存，无明文回退。对话通过所选服务商处理，调用费用由用户账号承担。记忆默认关闭：只在内存显示对话，不写磁盘，不携带上句上下文；开启后最多保存40条本机明文历史并发送最近20条。关闭记忆、取消收入授权、切换接口或清空记录会清除旧历史。用户主动输入的信息仍会发送给服务商。

收入授权默认关闭，仅自动发送作息状态；开启后发送当前月薪（分）、已赚、秒薪等快照。主动消息显示12秒气泡（每行约15个汉字，长句自动换行，居中在宠物上方），不自动打开聊天，启动和保存作息不补发；收入卡片打开时会临时让位给气泡，结束后恢复。网络错误不自动重试。默认30秒超时，不接受接口重定向。原有工资计算不依赖联网。

1.3.0 收入卡片从288缩至248逻辑像素，金额字号从38改为28，并减少留白；不同宠物大小继续使用相同卡片字号。

## 验证与打包

```powershell
npm test
npm run typecheck
npm run build
npm run test:desktop
npm run test:features
npm run test:ai
npm run test:bubble
npm run test:drag
npm run package
```

`npm run package` 会生成 `../release/SalaryPet-win32-x64/SalaryPet.exe`。打包版本首次启动也会从空设置开始。

## 计算口径

秒薪 = 税后月薪 ÷ 当月所有排定工作日的有效工作总秒数；午休不计入。应用按当前本地时间重新计算，不会把每秒四舍五入后的显示值累加。它是收入展示估算，不是考勤或工资结算。

## 角色参考

根据用户指定的“一二布布”角色和确认的白色“一二”形象绘制，参考图：https://c-ssl.duitang.com/uploads/blog/202112/31/20211231082620_b6122.jpg 。角色显示资源内置，运行时不从网络加载图片。

将 `SALARY_PET_PACKAGE_OUT` 设置为 `../release-yier-v1.3.3` 可将新版打包到独立文件夹；不设置时默认使用 `../release`。`SALARY_PET_EXECUTABLE` 可为 AI 桌面测试与打包测试指定 EXE；测试仅连接本地 HTTP 模拟接口，使用临时配置与假密钥。

1.3.3 使用系统鼠标DIP坐标拖动，窗口移动不会再通过页面screen坐标反馈偏移。`npm run test:drag` 验证固定鼠标不漂移、释放/取消/丢失捕获清理与位置持久化；`npm run test:drag-native` 会在Windows桌面注入物理鼠标输入并记录实际原生采样轨迹，仅在可接受鼠标短暂移动时运行。两者可通过 `SALARY_PET_EXECUTABLE` 验证最终打包版，使用隔离配置。完整提示词位于 `src/ai-prompts.ts`，普通聊天与主动规则分开，自定义替换预设，授权门禁仍在服务层。
