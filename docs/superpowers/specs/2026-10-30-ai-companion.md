# 一二 AI 陪伴与紧凑收入卡片

用户已在对话中批准开始实现，沿用用户自备 API Key，不再增加设计确认。

## 用户体验

设置新增独立的 AI 陪伴区，独立保存，不要求先填写工资。支持 OpenAI、DeepSeek、通义千问和自定义 OpenAI 兼容 Chat Completions 接口；提供启用开关、接口地址、模型、密码式密钥输入、移除密钥与测试连接。预设服务商填写地址和模型，仍可修改。空密钥输入表示保留已存密钥，不回填明文。测试连接使用当前草稿，不改动已保存设置。

称呼最多30字；人设有预设/自定义两种模式，预设温柔陪伴、活泼可爱、毒舌、打工人嘴替；自定义最多4000字。默认温柔陪伴。主动说话默认关闭，可选作息节点或偶尔一句；偶尔一句最多每30分钟一次，仅工作和午休时。作息节点只在实际跨入工作/午休/下班时触发，启动不补发，不在休息日发。失败后不自动重试。聊天窗口可通过卡片入口、右键和托盘打开。

聊天独立窗口支持发送、加载态、错误反馈和清空记忆。默认记忆关闭，关闭时不保存对话到磁盘且下次请求不携带旧消息；开启后最多保留40条本机历史，发送最近20条，跨重启保留。关闭记忆或清空记录会清除本机旧历史。聊天使用纯文本渲染。主动说话通过宠物上方短暂气泡展示，并在聊天窗口中显示；气泡可点击打开聊天，AI文本不控制动作或系统操作。

收入授权默认关闭：仅发送当前作息状态，不自动发送工资、秒薪、已赚金额、倒计时或排班。授权开启后才把当前实际收入快照加入请求。用户主动输入的信息会随聊天发送，界面说明清楚。取消授权会清除旧聊天，防止从历史继续发送先前收入。

密钥仅主进程持有，使用 Electron safeStorage 加密后保存；不可用时拒绝持久化密钥，不降级明文。AI网络请求全部由主进程发起，渲染进程 CSP 继续禁止网络。只接受 HTTPS，HTTP只允许本机回环地址方便本地模型。验证输入、30秒超时、拒绝跳转，响应限制大小，错误不包含密钥或原始响应。测试不使用用户真实工资/密钥，不向真实服务发收费请求。

红框收入卡片缩窄为248逻辑像素（原288），减少留白，金额字号28（原38），移除占空间的口号，保留今日已赚、状态、秒薪、下班倒计时、设置及聊天入口；字号不随宠物三档大小改变。

## 实现边界

新增纯配置/提示词模块、独立 AI 持久化与请求服务、主进程集成、设置与聊天页。原工资Store和计算不改格式。旧版位置、动作和大小兼容。默认关闭AI，未配置时给出设置入口，原功能独立可用。

验收：配置与请求载荷单元测试；真实本地HTTP模拟服务覆盖请求、密钥、错误、超时和历史；隔离Electron覆盖UI配置、人设切换、测试连接、对话、清空、重启、密钥加密、授权和紧凑布局；旧桌面测试与打包启动验证；截图检查和独立代码审查。交付版本1.3.0独立目录和完整ZIP，保留正在运行的旧进程。
